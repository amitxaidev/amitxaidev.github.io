How it works

Why pictures

You remember what you've seen move.

A wall of code tells you the answer. A picture shows you why it works. So we show the idea moving on screen first, and write the code after.

  • An everyday picture for each idea
  • Graphs wherever a comparison helps
  • Worked examples you can pause and try
