Hi, I'm Amit. I'm a backend engineer with 10+ years of building Java and Spring Boot microservices: Kafka event flows, Saga transactions, API gateways and the kind of systems that have to keep working when things fail.

I started Compiled Canvas because DSA is usually taught as a wall of code. I'd rather show you the idea moving on screen first and write the code after. The DSA in Java course is the first one: 105 episodes from Big O to dynamic programming, with 352 LeetCode problems on this site that come with hints and solutions. More courses are coming once this one is done.
