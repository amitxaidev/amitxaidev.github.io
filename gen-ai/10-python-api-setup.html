Python Setup for AI: API Keys and Environment Variables (.env)

Python setup for AI APIs: a virtual environment, an API key, a .env file and .gitignore, and loading the key safely with python-dotenv.

1Don't lose your money

You paste your API key into your code, push it to GitHub, and lose money before lunch. Here's how to stop that.

Bots scan public code for keys all day. A leaked key lets a stranger run AI calls on your bill.

Today, the setup companies use. A virtual environment, an API key, and a dot env file nobody else can see. About ten minutes.

key = "sk-…" # in your codePUSHED TO GITHUB → STOLENVIRTUAL ENVAPI KEY.env FILE

2Virtual environment

Step one. And skipping it is why so many projects break a month later.

A virtual environment is a private box of libraries for one project. Like a separate pencil box for each subject.

Make one with python dash m venv dot venv. Then activate it. On Mac and Linux, source dot venv slash bin slash activate.

On Windows, it's dot venv backslash scripts backslash activate. You'll see dot venv in brackets at the start of your terminal line.

Now install two libraries. The official Anthropic library, and python dot env.

project A: its own librariesproject B: its own librariespython -m venv .venvsource .venv/bin/activate.venv\Scripts\activate(.venv) APPEARS IN YOUR TERMINAL

3The api key

Your API key is a password to your wallet. Here's what it actually does.

Every call to an AI API sends your key. The provider uses it to know who's asking, and who pays.

You create one in your provider's console. For Claude, that's console dot anthropic dot com. You see the full key only once, so save it somewhere safe.

Treat it like your bank PIN. Never in your code, never in a screenshot, never in a chat message.

API KEY= WALLET PASSWORDyour code + key → providerprovider → bill to youconsole.anthropic.comshown only once!

4The .env file

So if the key can't live in your code, where does it live? In a tiny file called dot env.

One line. The name, an equals sign, your key. No quotes, no spaces.

Then the most important step. Add dot env to a file called dot gitignore. Now git never uploads it.

Your code stays public and shareable. Your key stays on your machine. That's the whole idea.

ANTHROPIC_API_KEY=your-key-hereNAME=valueNO QUOTES, NO SPACES.env.venv/GIT NEVER UPLOADS THESE

5Load the key in Python

Edit the code and press Run to try it right here, or copy it and run python3 load_key.py.

load_key.py · click to editDownload
# Lesson 10: load your API key from a .env file, never from the code.
#   1. python -m venv .venv            (then: source .venv/bin/activate   or   .venv\Scripts\activate on Windows)
#   2. pip install anthropic python-dotenv
#   3. create a file named .env with one line:   ANTHROPIC_API_KEY=your-key-here
#   4. add .env to .gitignore so it never reaches GitHub
import os
from dotenv import load_dotenv

load_dotenv()                                   # reads .env into the environment
key = os.getenv("ANTHROPIC_API_KEY")

if not key:
    raise SystemExit("No key found. Add ANTHROPIC_API_KEY=... to your .env file.")

print("Key loaded:", key[:7] + "..." + key[-4:])   # never print the whole key
print(".env in .gitignore:", os.path.exists(".gitignore") and ".env" in open(".gitignore").read())
▶ Output
Key loaded: sk-ant-...abcd

Here's how your code reads it. Load dot env reads the file into the environment.

Then os get env fetches the key by name. Your code never contains the key itself.

If it's missing, stop with a clear message. And when you print it, show only the first and last few characters. All the Python code is on compiled canvas dot com, ready to copy.

6Checklist

Before you write any AI code, run this checklist. It takes one minute, and it saves you from the costly mistake.

Virtual environment active. Libraries installed. Key in dot env. Dot env in dot gitignore. Key loaded with get env.

Leaked one anyway? Delete that key in the console right away, and make a new one. Deleting it stops it working.

Your turn. Pause. You type git status, and dot env shows up as a new file. What did you forget?

Adding dot env to dot gitignore. Do it before your first commit.

7Cheat sheet

  • One venv per project

  • Key = wallet password
  • Key → .env
  • .env → .gitignore
  • os.getenv(...)
