# 12. IPO

**LeetCode 502** · 🔴 Hard · Pattern: **Sort by capital + max-heap of profits**
🔗 Solve it here: [https://leetcode.com/problems/ipo/](https://leetcode.com/problems/ipo/)  
🌐 Interactive version (progress tracking, hints one by one): [https://amitxaidev.github.io/dsa/21-heaps/012-ipo.html](https://amitxaidev.github.io/dsa/21-heaps/012-ipo.html)

## The problem, in short

You start with capital w and can finish at most k projects. Each project needs some minimum capital to start and adds its profit to your capital when done. Maximise final capital.

> This is our own short summary. Read the full statement and examples on LeetCode, then try it yourself before opening the hints.

## Hints

<details>
<summary>💡 Hint 1</summary>

At any moment, among projects you can afford, pick the most profitable one.

</details>

<details>
<summary>💡 Hint 2</summary>

Sort projects by required capital; as capital grows, push newly affordable projects into a max-heap of profits.

</details>

## Approach

<details>
<summary>🧠 Show the approach</summary>

Sort by capital. Repeat k times: push all projects with capital &lt;= w into the max-heap; if it's empty, stop; else add the top profit to w.

</details>

## Java solution

<details>
<summary>✅ Show the answer</summary>

```java
import java.util.*;

class Solution {
    public int findMaximizedCapital(int k, int w, int[] profits, int[] capital) {
        int n = profits.length;
        Integer[] order = new Integer[n];
        for (int i = 0; i < n; i++) order[i] = i;
        Arrays.sort(order, (a, b) -> Integer.compare(capital[a], capital[b]));
        PriorityQueue<Integer> best = new PriorityQueue<>(Collections.reverseOrder());
        int i = 0;
        while (k-- > 0) {
            while (i < n && capital[order[i]] <= w) best.offer(profits[order[i++]]);   // newly affordable
            if (best.isEmpty()) break;
            w += best.poll();
        }
        return w;
    }
}
```

</details>

## Complexity

- **Time:** O(n log n + k log n).
- **Space:** O(n).

## Common mistake

⚠️ Re-scanning all projects every round — O(n·k).
