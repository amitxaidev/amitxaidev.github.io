Prefix Sum Explained: Any Range Sum in 1 Step | Java DSA

?What this episode covers

A million numbers and a million "what's the sum from here to there?" questions can take up to a trillion steps the slow way. With a prefix sum, each answer takes one subtraction.

The idea is the kilometre stones on an Indian highway. Each stone shows the distance from the start, so the distance between any two stones is one subtraction. A prefix array does the same thing for an array.

We build one step by step: for the array 2, 4, 1, 3, 5, the prefix array is 0, 2, 6, 7, 10, 15. So the sum from index 1 to 3 is prefix[4] − prefix[1], which is 10 − 2 = 8. Then we work through more examples, including one for you to try, compare the two approaches on graphs, write it in Java, and finish with a cheat sheet and a quiz.

◎What you'll be able to do

  • Why adding up a range again for every question is slow
  • How to build a prefix array that is one box longer than the input
  • The formula: sum from L to R = prefix[R + 1] − prefix[L]
  • The cost: O(n) to build, O(1) per query
  • Writing it in Java

!The mistake to watch for

Forgetting the +1. prefix[R] − prefix[L] leaves out the last number of the range. Use long for the prefix array when values get big.
