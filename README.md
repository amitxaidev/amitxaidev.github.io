## How every course works

1. **Watch** the episode on YouTube.
2. **Understand** — read the topic intro and each problem's Understanding section.
3. **Try** it yourself, opening one hint at a time when you're stuck.
4. **Check** the approach and solution, and learn the common mistake.
5. **Track** your progress on the website.
